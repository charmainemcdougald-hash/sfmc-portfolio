# What I Focus On

When I design a marketing automation solution, I look beyond whether the code simply works.

I also consider:

- Can the solution scale?
- Is it understandable to the next developer?
- Can marketing teams operate it efficiently?
- What happens when data is missing or incorrect?
- How will failures be detected?
- Is the customer experience protected?
- Are consent and suppression requirements respected?
- Can the solution be reused instead of rebuilt?
- How will the program be tested and measured?

That combination of technical execution, business understanding, and operational thinking is the approach I bring to Salesforce Marketing Cloud.
